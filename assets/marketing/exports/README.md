# Trickpad icon exports

These PNGs are flattened marketing renders generated directly from `icons/Trickpad.icon` with Icon Composer's macOS 27 renderer. Each file is rendered at its stated size rather than downscaled from a larger PNG. All exports are 16-bit RGBA with an embedded Display P3 profile.

## macOS

`macOS/default` and `macOS/dark` contain native renders at 16, 32, 64, 128, 256, 512, 1024, and 2048 pixels. Use 2048 as the general marketing master and the exact-size files for fixed small placements.

## watchOS

`watchOS/default` contains the circular watchOS composition at 32, 64, 128, 256, 512, 1024, 1088, and 2176 pixels. Apple defines 1088 pixels as the watchOS layout size; 2176 is its 2x marketing master. watchOS has one appearance rather than separate default and dark variants.
